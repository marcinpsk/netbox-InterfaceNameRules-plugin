# Contributing

See the [Contributing Guide](https://github.com/marcinpsk/netbox-InterfaceNameRules-plugin/blob/main/CONTRIBUTING.md) in the repository.

## Community Rules

Example interface name rules for various vendors are maintained in the
[`contrib/`](https://github.com/marcinpsk/netbox-InterfaceNameRules-plugin/tree/main/contrib) directory,
organized by vendor:

- `cisco.yaml` — Cisco IOS-XR platforms
- `juniper.yaml` — Juniper Junos platforms
- `ufispace.yaml` — UfiSpace SONiC platforms
- `converters.yaml` — Media converter offset rules

PRs welcome for additional platforms.
