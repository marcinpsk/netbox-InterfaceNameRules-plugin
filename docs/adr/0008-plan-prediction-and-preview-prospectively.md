# Plan prediction and preview prospectively

Rowless prediction and the interactive preview build prospective family plans through the same naming rules installed execution follows. One shared target module names every family, so an installed plan, a prospective plan and a structural plan cannot spell the same family differently. A prospective plan carries names rather than row snapshots and the executors reject one by type, so a preview can never become an executable snapshot and prediction can describe a family NetBox has not created yet. Interactive apply ignores the preview object and plans again from live rows, so a change between the two is replanned rather than written over. A plan the live topology blocks previews and predicts no change, because the apply path would build nothing there either.
